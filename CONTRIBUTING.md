# Contributing to the UND Industries Community

Thanks for helping improve UND products and services.

## Best ways to contribute

- Report reproducible bugs.
- Suggest features with a clear user problem and expected outcome.
- Share product feedback with context about what worked and what did not.
- Help answer public questions when you can do so accurately.

## Before posting

Search existing issues first to avoid duplicates. Remove passwords, tokens, private URLs, personal data, account identifiers, screenshots containing secrets, and confidential material.

For security vulnerabilities or accidental sensitive-data exposure, do not open a public issue. Follow `SECURITY.md`.

## Good bug reports include

- Product or service name
- Platform/device/browser
- App or version information if known
- Steps to reproduce
- Expected behavior
- Actual behavior
- Frequency
- Safe screenshots or logs with sensitive information removed

## Good feature requests include

- The problem you are trying to solve
- Who benefits
- What outcome you want
- Any workaround you use today
- Why the change would matter

## Pull requests

This repository is primarily a public community hub, not the source repository for UND products. Do not submit proprietary application code or attempt to mirror private UND repositories here. Small improvements to public community documentation may be considered.
