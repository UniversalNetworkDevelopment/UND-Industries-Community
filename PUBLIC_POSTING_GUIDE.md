# Public Posting & Privacy Guide

This repository is public. Anything posted here may be copied, indexed, cached, quoted, or redistributed by others.

## Safe to share

- Feedback about public UND products and services
- Feature ideas based on public behavior
- Reproducible bug reports that do not expose sensitive data
- Public documentation links
- Screenshots that have been reviewed and redacted
- General questions and community discussion

## Never share publicly

- Passwords, API keys, access tokens, session cookies, recovery codes, private keys, or secrets
- Private repository content, proprietary source code, internal prompts, unpublished architecture, or infrastructure details
- Customer records, private messages, billing details, personal contact information, or other personal data
- Internal company documents, contracts, credentials, logs containing secrets, or private incident details
- Security exploit details for a live UND system before a private reporting path has been established

## Before posting a screenshot or log

1. Crop to the minimum relevant area.
2. Remove names, email addresses, account IDs, tokens, URLs containing secrets, file-system paths that reveal private information, and internal hostnames.
3. Re-read the image or text for accidental secrets before posting.
4. If uncertain, do not post it publicly.

## If sensitive information is posted accidentally

Delete or edit the public content if possible and contact UND privately. Treat exposed credentials as compromised and rotate or revoke them. Deleting a public post alone is not sufficient because copies may already exist.

For potential security vulnerabilities, follow `SECURITY.md` rather than opening a public issue or discussion.
