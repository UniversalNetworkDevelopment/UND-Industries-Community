# UND Industries Community

Welcome to the official public community hub for UND Industries.

This repository is the public place for product feedback, feature ideas, support questions, reproducible bug reports, and community discussion related to UND products and services. It is intentionally separated from UND's private development repositories.

## Start here

- **Bug report:** open an issue using the bug template.
- **Feature request:** open an issue using the feature template.
- **General feedback:** use the feedback template or a GitHub Discussion when Discussions are enabled.
- **Support:** see `SUPPORT.md` and use the support template.
- **Security concern:** do **not** post details publicly. Follow `SECURITY.md`.
- **Before posting screenshots, logs, or technical details:** read `PUBLIC_POSTING_GUIDE.md`.
- **Contributing:** see `CONTRIBUTING.md`.
- **Community behavior:** see `CODE_OF_CONDUCT.md`.
- **How this community is managed:** see `GOVERNANCE.md`.

## What belongs here

- Product feedback and suggestions
- Feature requests
- Reproducible bug reports
- Questions about public-facing UND products
- Community ideas and discussion
- Public release and announcement references

## What does not belong here

Do not post passwords, API keys, access tokens, private keys, recovery codes, customer records, personal data, private company documents, private repository content, proprietary source code, internal prompts, unpublished infrastructure details, or other sensitive information.

If a report involves a security vulnerability or sensitive-data exposure, do not publish the details in a public issue, discussion, comment, pull request, screenshot, or log. Follow `SECURITY.md` instead.

## Public by design

Everything in this repository should be safe for public viewing. Community contributions may be indexed, cached, quoted, copied, or redistributed by third parties. Review material carefully before posting it.

## Community standards

Be respectful, stay on topic, avoid spam, and provide enough context for others to understand and reproduce technical problems. UND may moderate, lock, edit, or remove content that exposes sensitive information, violates community rules, or creates security risk.

## Repository purpose

This repository is a communication and feedback surface only. It should not contain UND private application code, credentials, secrets, customer data, private operational material, or unpublished internal architecture.
