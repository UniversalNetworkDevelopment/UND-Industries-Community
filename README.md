# UND Industries Community

Welcome to the official public community hub for UND Industries.

Use this repository to share product feedback, feature ideas, support questions, bug reports, and community discussion related to UND products and services.

## What belongs here

- Product feedback and suggestions
- Feature requests
- Reproducible bug reports
- Questions about public-facing UND products
- Community ideas and discussion
- Release and announcement references

## What does not belong here

Do not post passwords, API keys, access tokens, private keys, recovery codes, customer records, private company documents, internal source code, unpublished infrastructure details, or other sensitive information.

If a report involves a security vulnerability or sensitive-data exposure, do not publish the details in a public issue. Follow `SECURITY.md` instead.

## Community standards

Be respectful, stay on topic, avoid spam, and provide enough context for others to understand and reproduce technical problems. UND may moderate, lock, or remove content that exposes sensitive information, contains abuse, or creates security risk.

## Repository purpose

This repository is intentionally separated from UND's private development repositories. It is a public communication and feedback surface only and should not contain proprietary application code or internal operational material.
