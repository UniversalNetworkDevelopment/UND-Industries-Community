# Security Policy

This public repository is for community feedback and discussion. Please do not disclose sensitive security information in public issues, pull requests, discussions, comments, or screenshots.

## Do not post publicly

- Passwords, access tokens, API keys, private keys, recovery codes, or credentials
- Customer or user personal data
- Private company documents or internal source code
- Unpublished infrastructure details that could increase security risk
- Step-by-step exploit instructions against a live UND system

## Reporting a potential vulnerability

If you believe you found a security vulnerability or accidental exposure of sensitive information, do not publish the technical details here. Contact UND through its official private support or business contact channel and provide only the minimum information needed to establish contact until a secure reporting method is agreed.

If sensitive information is accidentally posted publicly, remove it immediately if you can and notify UND through a private channel. Assume any public secret is compromised and rotate or revoke it rather than relying only on deletion.

## Scope

This file does not authorize security testing, access to private repositories, accounts, infrastructure, or data. Only test systems and accounts you are authorized to use.
